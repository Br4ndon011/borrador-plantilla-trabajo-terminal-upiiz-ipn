\chapter{Antecedentes}
\label{cap:antecedentes}

Alumnos de la Unidad Profesional Interdisciplinaria de Ingeniería Campus Zacatecas IPN (UPIIZ) han realizado diversos proyectos que se relacionan directamente con el presentado en el actual protocolo, por lo que se ha realizado una investigación sobre cómo es que estos proyectos pueden servir como base para desarrollar e implementar estas tecnologías en la propuesta que se está presentando.

Comenzando cronológicamente, en el año 2023, los alumnos Alan Ismael Rodríguez Vega, Braulio Israel Sánchez Hernández y Jesús Ávila Varela desarrollaron el proyecto con el título “Robot de servicio y distribución de comida en un establecimiento”, con el cuál realizaron el diseño mecatrónico de un robot móvil en un entorno controlado para el servicio de distribución de alimentos. Este documento es sumamente importante debido a que se pueden tomar como referencia los cálculos de fuerza para determinar la potencia necesaria de los motores y de la batería e implementarlo en el proyecto del presente protocolo \cite{A1}.

Para el año de 2025, el alumno Jesús Alfredo Juárez Madera presentó el proyecto con el título “Robot móvil transportador de concentradores portátiles de oxígeno”, de este trabajo se puede rescatar la tecnología utilizada para hacer posible la navegación autónoma, ya que utilizaron marcadores visuales que se pueden tomar como referencia para utilizar algo parecido o mejorar este sistema \cite{A2}.

Del mismo modo, en 2025, se presentó el trabajo con el título “Diseño y construcción de un prototipo a escala de un Robot Móvil Autónomo”, realizado por los alumnos Jesús Dávila Martín del Campo y Julio Alcalde Navarro. En él, se puede investigar acerca del sistema que utilizaron para el procesamiento de imágenes y el sistema que tiene para evitar colisiones, al igual que se puede estudiar la eficiencia energética del mismo, ya que tiene la capacidad de funcionar de manera continua hasta 60 minutos \cite{A3}.

Todos estos trabajos se tomarán como referencia o fuentes de investigación para enriquecer los conocimientos que se pondrán en práctica para la realización del proyecto presentado.
