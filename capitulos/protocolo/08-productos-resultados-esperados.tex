\chapter{Productos o resultados esperados}
\label{cap:proto-productos-esperados}

Como resultado del desarrollo del proyecto, se espera obtener un sistema de transporte y entrega que pueda desplazarse de manera autónoma dentro de un espacio interior de hasta 5×5 m. El usuario podrá seleccionar mediante una interfaz el lugar al que desea enviar el producto y, a partir de esta indicación, el sistema determinará la trayectoria que deberá seguir para llegar al destino, sin que sea necesario establecer previamente una ruta.

Durante el recorrido, los sensores proporcionarán información sobre lo que se encuentra alrededor del sistema, permitiendo detectar obstáculos y realizar los cambios necesarios en la trayectoria gracias al sistema de visión artificial implementado. De esta manera, el dispositivo podrá continuar su recorrido hasta el punto indicado sin depender de una intervención constante del usuario.

El prototipo también estará diseñado para transportar una carga de hasta 1.0 kg y mantener un movimiento adecuado durante el recorrido. Además, se considerará un tiempo de funcionamiento de hasta 15 minutos y una interfaz que permita al usuario seleccionar el destino. 

Finalmente, para poder comprobar el funcionamiento de la propuesta especificada en el protocolo, se realizarán distintas pruebas que tengan relación con el desplazamiento, como la llegada al destino, el seguimiento de la trayectoria, detección de obstáculos y el tiempo de operación. Principalmente se buscará que cumpla con el objetivo general de transportar un objeto con una masa de máximo 1.0 kg de un punto a otro. 
Para comprobar el funcionamiento de la propuesta, se realizarán diferentes pruebas relacionadas con el desplazamiento, la llegada al destino, el seguimiento de trayectoria, la detección de obstáculos, el transporte de la carga y el tiempo de operación. A partir de los resultados obtenidos se podrá determinar si el sistema cumple con las condiciones establecidas para el proyecto y qué aspectos podrían necesitar ajustes.
