\chapter{\tituloValidacion}
\label{cap:validacion}

En este capítulo se exponen los protocolos de prueba experimentales, las métricas cuantitativas empleadas y los resultados obtenidos para evaluar rigurosamente el desempeño del sistema mecatrónico.

% ------------------------------------------------------------------------------
\section{Métricas cuantitativas de evaluación}
\label{sec:validacion-metricas}

Para cuantificar el desempeño del sistema, se emplean las siguientes métricas estadísticas de error y respuesta transitoria:

\begin{enumerate}
    \item \textbf{Error instantáneo del sistema:}
    \begin{equation}
        e(t) = r(t) - y(t)
        \label{eq:error-instantaneo-gen}
    \end{equation}
    \item \textbf{Error Absoluto Medio ($\text{MAE}$):}
    \begin{equation}
        \text{MAE} = \frac{1}{N}\sum_{k=1}^{N} |e(k)|
        \label{eq:mae-gen}
    \end{equation}
    \item \textbf{Error Cuadrático Medio ($\text{RMSE}$):}
    \begin{equation}
        \text{RMSE} = \sqrt{\frac{1}{N}\sum_{k=1}^{N} e^2(k)}
        \label{eq:rmse-gen}
    \end{equation}
    \item \textbf{Eficiencia de cumplimiento de tareas o misiones ($\eta$):}
    \begin{equation}
        \eta = \frac{N_{\text{éxitos}}}{N_{\text{ensayos totales}}} \times 100\,\%
        \label{eq:eficiencia-gen}
    \end{equation}
\end{enumerate}
