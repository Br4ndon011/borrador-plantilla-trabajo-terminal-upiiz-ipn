\chapter{Desarrollo del Sistema Mecatrónico}
\label{cap:desarrollo}

Para la realización de este proyecto, se empleará la metodología de diseño mecatrónico.

% ------------------------------------------------------------------------------
\section{Identificación de necesidades}
\label{sec:id-necesidades}

El presente trabajo propone el diseño y desarrollo de un robot móvil autónomo para el transporte de objetos dentro de un entorno cubierto, con superficie plana y un área de desplazamiento de hasta 5×5 m. El sistema estará diseñado para trasladar una carga de hasta 1.5 kg desde un punto base hasta un punto definido por el usuario. Para realizar está tarea, contará con un sistema de navegación que le permita reconocer el entorno, determinar su posición y establecer de manera autónoma la trayectoria necesaria para llegar al punto indicado. Se contempla un tiempo de funcionamiento de hasta 15 minutos, con el propósito de disminuir la intervención del usuario durante el traslado.

Debido a los requerimientos y las funciones que se deben de cumplir en el sistema robótico, se han identificado  una lista de necesidades del diseño (\tabref{tab:necesidades}), que se relacionan principalmente con la navegación autónoma, los costos, interacción con el usuario, entre otras necesidades. La tabla fue realizada a base de las exigencias operativas de un sistema de navegación autónoma y se toma un nivel de importancia en donde 1 es el más importante y el 5 es el menos importante:

\section{Análisis del Problema}
\label{sec:ana-problema}
El problema que existe se presenta debido a los altos costos de los robots autónomos comerciales y a las limitaciones de los sistemas AGV que dependen de trayectorias ya definidas para su desplazamiento. Esta problemática puede solucionarse mediante el desarrollo de un prototipo de robot móvil con navegación autónoma que mantenga costos de fabricación bajos sin sacrificar su funcionamiento y estabilidad. Es por eso que se plantea la descripción de un prototipo AMR mediante los diagramas funcionales IDEF-0 que se presentan a continuación.

\section{Generación de posibles soluciones}
\label{sec:soluciones}

A partir de las especificaciones determinadas, se plantean diferentes propuestas para el diseño del robot, considerando las alternativas disponibles para la estructura, sistema de locomoción, sensores, motores y componentes electrónicos. Se analizarán las características de cada diseño propuesto para determinar cuáles pueden cumplir con las necesidades y condiciones que se establecieron para el proyecto.   

\section{Selección de la propuesta}
\label{sec:propuesta}

Una vez planteadas las diferentes propuestas, se realizará una comparación entre ellas tomando en cuenta aspectos como el funcionamiento, costo, facilidad de construcción, disponibilidad de componentes y cumplimiento de las especificaciones establecidas. A partir de esta comparación se descartaran diseños para seleccionar la propuesta que se utilizara para continuar con el desarrollo del proyecto.

\section{Diseño detallado}
\label{sec:diseño_detallado}
Una vez seleccionada la propuesta, se realizará el diseño de los diferentes elementos que conforman el robot. Por la parte mecánica se definirá la estructura y el sistema de locomoción, considerando la carga que deberá trasladar. En la parte electrónica se seleccionan los componentes necesarios para el funcionamiento del robot y la alimentación de los diferentes elementos. También se  implementará el sistema de control para el desplazamiento y la evasión de obstáculos, así como la interfaz que permitirá al usuario definir el punto de destino y finalmente, se desarrollará la HMI, destinada para que exista una interacción con el usuario.

\section{Elaboración de planos y documentación}
\label{sec:Planos_documentacion}
Con el diseño definido, se dará paso a desarrollar los planos y diagramas necesarios para la construcción del robot. Se incluirán los planos de la estructura, diagramas eléctricos y de conexión, así como diagramas relacionados con el sistema de control y la interfaz del usuario. En esta etapa también se realizarán simulaciones para detectar a tiempo algún error antes de la construcción del prototipo.

\section{Elaboración del prototipo}
\label{sec:Elab_prototipo}

A partir del diseño y los planos realizados, se procederá a la construcción del prototipo durante la unidad de aprendizaje de Trabajo Terminal 2. En esta etapa se realizará la fabricación y ensamble de la estructura, así como la incorporación del sistema de control y visión artificial.


\section{Pruebas y Ajustes}
\label{sec:Pruebas_Ajustes}

Una vez construido el prototipo, se realizarán las pruebas de funcionamiento en el área de trabajo establecida, considerando diferentes rutas y puntos de destino. Se comprobará el traslado del robot, el transporte de la carga, la detección y evasión de obstáculos, así como la interfaz del usuario. A partir de los resultados obtenidos se realizarán los ajustes necesarios hasta obtener el funcionamiento propuesto del prototipo.
