\chapter{Estado del Arte}
\label{cap:estado-del-arte}

Actualmente, la implementación de robots móviles autónomos ha comenzado a utilizarse cada vez más en tareas donde se necesita transportar o entregar objetos dentro de diferentes espacios. Algunas de las aplicaciones que más se han encontrado están relacionadas con restaurantes, hospitales, almacenes, hoteles y otros lugares interiores. Con el objetivo de mostrar el panorama tecnológico de robots autónomos en el mercado, se presentarán algunos de los sistemas ofertados en la actualidad.

% ------------------------------------------------------------------------------
\section{Robot de entregas y limpieza: AutoXing AX1612 MARS}
\label{sec:EDA_1}

El robot AutoXing AX1612 MARS es un robot móvil autónomo (AMR) de servicio, diseñado específicamente para la entrega y logística en escenarios de fábricas, hospitales, y grandes espacios comerciales sin la necesidad de algún marcador físico para su navegación [EDA 1]. Capaz de transportar hasta 80 kg a 1.2 m/s, que garantiza la estabilidad de la carga incluso en superficies irregulares mediante su suspensión independiente. Su sistema de evasión 3D fusiona LiDAR, cámaras RGBD y sensores ultrasónicos, permitiendo calcular trayectorias y esquivar obstáculos de apenas 3 cm en tiempo real [EDA 2].

\section{Sistema de detección de usuarios y comunicación proactiva para un robot autónomo de servicio}
\label{sec:EDA_2}

Un grupo de investigadores del Instituto Universitario en Ingeniería Mecatrónica y Sistemas Ciber Físicos (IMECH.UMA) presentó un sistema avanzado de navegación y comunicación para un robot de servicios. El objetivo es lograr que el robot se desplace por lugares concurridos evitando chocar contra personas y comportándose de manera socialmente aceptable y respetuosa. Para lograrlo, los investigadores equiparon al robot con láser de navegación y un sistema de cámaras 3D instalados en una cabeza móvil. El software que desarrollaron utiliza inteligencia artificial para detectar la postura de las personas y agruparlas. Con estos datos recolectados, el sistema de navegación crea zonas de confort invisibles alrededor de los usuarios. Esto permite que el robot pueda recalcular las trayectorias para no invadir el espacio personal de la gente alrededor, esquivando con naturalidad como lo haría un humano [EDA 3].


\section{Robot móvil autónomo para entrega PUDU SwiftBot}
\label{sec:EDA_3}

El PUDU SwiftBot es un robot móvil autónomo de servicio desarrollado para realizar tareas de entrega en espacios comerciales, principalmente en restaurantes y establecimientos donde existe circulación constante de personas. El sistema está diseñado para transportar productos mediante bandejas y realizar diferentes modos de servicio, entre ellos entrega de alimentos, entrega general, recorridos e interacción con los usuarios. Cuenta con una capacidad de carga de hasta 35 kg, puede incorporar de tres a cinco bandejas y alcanza una velocidad ajustable de entre 0.5 y 1.2 m/s. Además, cuenta con recarga automática, lo que permite que el robot regrese a su estación cuando requiere energía. [EDA 4]

\section{PUDU BellaBot}
\label{sec:EDA_4}

El PUDU BellaBot es un robot de servicio diseñado principalmente para realizar entregas dentro de restaurantes y establecimientos de alimentos. Su estructura incorpora bandejas para transportar productos y está orientada a facilitar el traslado de alimentos desde un punto determinado hasta diferentes zonas del establecimiento. PUDU Robotics lo clasifica como un robot de entrega de alimentos dentro de su línea de robots comerciales [EDA 5].

El sistema integra diferentes elementos destinados a la navegación y detección de su entorno, permitiendo que el robot se desplace en espacios donde existan personas, mesas y otros obstáculos. Además del desplazamiento, BellaBot incorpora elementos de interacción con los usuarios, por lo que su función no se limita únicamente al transporte.

\section{Sistema de gestión y control de entrega de paquetes — ESPOL}
\label{sec:EDA_5}

En 2023, Párraga Guerrero y Valladarez González desarrollaron en la Escuela Superior Politécnica del Litoral (ESPOL) el proyecto “Desarrollo y diseño de un sistema de gestión y control de entrega de paquetes en entornos interiores para un robot móvil de servicio”. El proyecto plantea el uso de un robot móvil para realizar entregas de paquetes dentro de espacios cerrados, tomando como referencia lugares como restaurantes, hoteles y eventos.

El trabajo no considera únicamente el movimiento del robot, sino también la organización y el control de las entregas. Para esto, se toman en cuenta aspectos como la navegación, la odometría, el control y la comunicación entre los diferentes elementos del sistema. Este proyecto se relaciona con la propuesta planteada, ya que también se contempla que el usuario indique un destino y que el robot realice el recorrido de manera autónoma [EDA 6].
