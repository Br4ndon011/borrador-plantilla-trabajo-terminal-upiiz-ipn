\chapter*{Resumen}
\addcontentsline{toc}{chapter}{Resumen}
\ifProtocolo
    \addcontentsline{toc}{section}{Palabras clave}
\fi

El presente protocolo consiste en el diseño y desarrollo de un robot móvil autónomo que permita transportar objetos de hasta 1kg dentro de un espacio interior. La propuesta surge de buscar una alternativa más accesible que los robots autónomos comerciales y que al mismo tiempo no dependa de rutas establecidas previamente. El usuario podrá indicar el lugar al que desea enviar el objeto mediante una interfaz, y el robot se encargará de desplazarse hasta ese destino de manera autónoma. Para el desarrollo del robot se integrarán diferentes áreas de la mecatrónica, trabajando en conjunto para lograr que el sistema pueda desplazarse, reconocer su entorno, tomar decisiones y responder a las condiciones que se presenten durante su recorrido. A partir de los recursos disponibles y de las características planteadas, se busca desarrollar el robot como una alternativa para el transporte autónomo de objetos en espacios interiores y bajo condiciones controladas.

\vspace{1.5em}
\noindent\textbf{Palabras clave:} Robot móvil autónomo, navegación autónoma, transporte de objetos, robot de servicio, robótica móvil.
